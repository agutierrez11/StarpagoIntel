# StarpagoIntel

Repositorio de Inteligencia Comercial y Estrategia de Expansión LATAM para Starpago. 
Contiene el material estratégico preparado para el proceso de adquisición corporativa (Payment Sales Manager - LATAM).

## Documentos Clave

1. **[STARPAGO_INTERVIEW_PLAYBOOK.md](./STARPAGO_INTERVIEW_PLAYBOOK.md)**
   El playbook central con guiones orales (método STAR), manejo de objeciones y métricas de adquisición (Top 8%, 50M+ Outbound). Validado con la metodología 5-LLM Council.

2. **[starpago_latam_entry_strategy.md](./starpago_latam_entry_strategy.md)**
   El mapa competitivo profundo dividiendo el mercado en Brasil (Independiente/Pix) e Hispanoamérica. Mapeo de asociaciones (AIEJA, IBJR) y verticales (iGaming, E-commerce, Enterprise).

3. **[STARPAGO_SCREENING_RESPONSE.md](./STARPAGO_SCREENING_RESPONSE.md)**
   Respuestas redactadas en inglés para el primer filtro técnico, enlazando la experiencia corporativa y consultoría Cross-Border (Perú, Argentina, Colombia).

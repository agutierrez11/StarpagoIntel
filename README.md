# StarpagoIntel

Repositorio de Inteligencia Comercial y Estrategia de Expansión LATAM para Starpago. 
Contiene el material estratégico preparado para el proceso de adquisición corporativa (Payment Sales Manager - LATAM).

1. **[STARPAGO_DRIVE_MARKET_INTELLIGENCE.md](./STARPAGO_DRIVE_MARKET_INTELLIGENCE.md)**
   La matriz completa de inteligencia comercial extraída del Google Drive: 17 competidores en Hispanoamérica y Brasil (Océano Rojo vs. Océano Azul) con las estrategias exactas de contraataque para Starpago.

2. **[STARPAGO_5LLM_COUNCIL_STRATEGY.md](./STARPAGO_5LLM_COUNCIL_STRATEGY.md)**
   Informe completo de la deliberación del 5-LLM Council (Claude, GPT-4o, Gemini, DeepSeek, Kimi/Manus), auditoría de la estrategia LATAM y dictamen del Chairman.

3. **[STARPAGO_INTERVIEW_PLAYBOOK.md](./STARPAGO_INTERVIEW_PLAYBOOK.md)**
   El playbook central con guiones orales (método STAR), métricas auditadas ($69.4M TPV YTD, $2.39M ticket promedio), tácticas para la entrevista con el Senior BDM y el Roadmap GTM.

4. **[teleprompter.html](./teleprompter.html)**
   Dashboard interactivo navegable tipo teleprompter para pantalla secundaria durante la videollamada.

5. **[starpago_latam_entry_strategy.md](./starpago_latam_entry_strategy.md)**
   Mapa competitivo dividiendo Brasil (Independiente) e Hispanoamérica. Mapeo de asociaciones (AIEJA, IBJR) y verticales (iGaming, E-commerce, Enterprise).

6. **[STARPAGO_SCREENING_RESPONSE.md](./STARPAGO_SCREENING_RESPONSE.md)**
   Respuestas redactadas en inglés para el filtro técnico inicial.

## Bases de Datos y Evidencia (Carpeta data/)
- **Datos_Adquisicion_21_22.xlsx** & **Deals para rentabilidad.csv**: Cruce de datos que valida los 55.6 Millones en volumen procesado total (90% Outbound).
- **Starpago_Mapa_Competitivo.csv**: La inteligencia extraída del Google Drive sobre el ecosistema de casinos y competidores LATAM.
- **Directorio_Amexvid.csv**: Padrón institucional para targetear e-sports.
